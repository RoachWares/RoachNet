# RoachNet 1.1.0

Release date: 2026-10-12
Version/build: 1.1.0 / 110
Platform: Apple Silicon Mac, macOS 14 or later
Installer: `RoachNet-Setup-macOS.dmg` (ad-hoc signed, not Apple-notarized — see "Opening the installer" below)
Companion: RoachNet-iOS 0.3.0 (separate release; follows the Mac's theme and needs 1.1 for that)

RoachNet 1.1 is the first feature release on the native runtime. RoachClaw runs on RoachNet's own inference engine instead of a bundled Ollama, and that engine serves the Ollama, OpenAI and Anthropic APIs with tools, structured output and parallel requests. The Org gets its boards on the Mac, works with the coding agents you already use (Claude Code, Codex and others), and is traced end to end. Your Claude and ChatGPT plans can stand in as models. A model too big for one Mac can be split across several with RoachNet Cluster. The app learns themes, the Maps pane draws the map packs you install, and the core install shrinks to what you use. It includes every fix in 1.0.6 and 1.0.7 and adds a per-launch token to the local API. It was gated by hand on an M2 Pro running macOS 26.6.1 (`docs/release-gates/1.1.0-mac-gate-results.md`).

## What's new

### RoachClaw on RoachInference

- RoachNet no longer bundles or installs Ollama. RoachClaw runs on RoachInference, a GGUF engine with hand-written Metal kernels, served by `roachnet-runtime` at `127.0.0.1`. Models in an existing Ollama folder are read in place, so nothing downloads twice.
- **Every API your tools already speak:** Ollama (`/api/chat`, `/api/generate`, `/api/embed`, `/api/create`, `/api/show`, `/api/ps` and the rest), OpenAI (`/v1/chat/completions`, `/v1/completions`, `/v1/responses`, `/v1/embeddings`, `/v1/models`) and Anthropic (`/v1/messages`, token counting), streamed or not.
- **Tools, structured output and thinking.** Tool calls in each API's own shape, JSON mode and JSON Schema enforced while the model writes, and thinking turned on or off for models that reason first. Modelfiles (`FROM`, `SYSTEM`, `PARAMETER`, `MESSAGE`) make new models that share the original's weights on disk.
- **Parallel requests.** A model answers up to four requests at once while memory allows. Each conversation keeps its own cache, so the next turn only evaluates what's new, and agents that share a long system prompt start from a copy of it instead of evaluating it again.
- **Memory-aware.** Before loading, RoachNet works out what a model needs. It unloads idle models, then shortens the context, and refuses with the numbers rather than letting the Mac swap. Keys and values are stored in half precision, so the same memory holds twice the context.
- **Speed**, on an M2 Pro with the same qwen3 8B file Ollama 0.33.2 uses (665-token prompt): prompt evaluation runs at 181 tok/s (Ollama: 267) and decode at 18.7 tok/s (Ollama: 22.0), or 20.5 tok/s with a short prompt. Earlier measurements against Ollama 0.40.1 put decode at about 91% of Ollama's speed on 1.5B and 3B models and faster on 0.5B. CPU and Metal produce identical tokens on the reference models. `docs/NATIVE_INFERENCE.md` has the details.
- To keep using an Ollama you installed yourself, set `ROACHNET_INFERENCE_ENGINE=ollama`.
- Model pulls resume where they stopped, try again on their own when the connection stalls for 90 seconds, and are checked by SHA-256 before they're installed.

### RoachNet Cluster

- Split one model across several Macs on your network: each Mac runs a range of its layers, and the reply streams back as if one Mac ran it. Pair Macs with a code in Settings › Models › RoachNet Cluster; Macs on the same network show up there to pick from.
- Links between Macs are authenticated with the pairing key and encrypted. A Mac that doesn't have the model gets just its part, checked by SHA-256 and resumable. If a Mac drops out mid-reply, that request fails, and the next one plans the model again with the Macs still there.
- By default only models too big for this Mac are split; you can split every model instead.

### Your own agents and plans

- **Bring your own agents.** Claude Code, Codex, Gemini CLI, OpenCode and Cursor CLI can join an Org and work with its other agents through issues, comments, @mentions and sub-issues. RoachNet runs your own signed-in CLI, so it never sees your account's credentials. Hire one from Org › Agents › Hire Agent.
- **Claude and ChatGPT plans as models.** Turn them on in Settings › RoachClaw › Subscriptions, and `claude:…` and `codex:…` models work in RoachClaw chat, for Org agents and on RoachNet's OpenAI and Ollama APIs. The replies come from your own Claude Code or Codex CLI, with no tools, in an empty folder.

### RoachTrace

- Every Org run, RoachClaw chat and model call is traced: tokens (with how many were reused from the cache), cost, latency, time to first token, speed, and scores. Org › Traces shows them.
- Secrets are scrubbed before anything is written, traces stay on your Mac in files only your account can read, and old ones are pruned. Settings › RoachClaw › Tracing can also send them to Langfuse or any OpenTelemetry collector.

### Org

- The Org desk has five boards: **Desk** (approvals, agents, invites), **Issues** (file, assign, change status, comment), **Org chart**, **Routines** (scheduled work for an agent, run now, pause) and **Budgets** (monthly limits for the company or one agent, hard stop, incidents).
- An agent that fails says why, with **Try again**.

### Themes

- 31 built-in themes and 13 snippets in Settings › Appearance, plus an editor for every color, font, radius, shadow, glass layer and background. Themes are JSON files: export one, share it, or drop one into the themes folder and it appears.
- Every built-in theme is tested for readable text in each mode it ships. Signal dark is the 1.0 look.
- Theme packs install from RoachNet Apps (the Halloween Collection and Retro Terminals to start). The iOS companion 0.3.0 follows the theme you pick on the Mac.

### Feature packs

- Panes, speech models, map collections, knowledge bundles and themes are packs. Settings › Packs shows what each one is, what it touches and what removing it would leave behind. Removing a pack keeps its data unless you choose to retire it.

### Maps, library and downloads

- The Maps pane draws the PMTiles packs you install (50 states, DC, five territories and a world overview): pan, zoom, fit, GPS fix and route, labels, OpenStreetMap and Protomaps credit. No tile server, no web view.
- Map, Kiwix and Wikipedia collections update from apps.roachnet.org while you're online and fall back to the bundled lists offline.
- Downloads survive a stall: they resume with a Range request instead of failing after ten minutes.

## Security

- **Local API token.** RoachNet.app starts the runtime with a fresh token each launch, and every route except `GET /api/health` (and Org requests carrying a member key) needs it or a RoachClaw API token with the right scope. Other programs on your Mac can no longer drive the API just because they can reach `127.0.0.1`. Make, scope and revoke RoachClaw API tokens in Settings › RoachClaw.
- **RoachTail.** Peer tokens are compared in constant time and stop working after 90 days unused (`ROACHTAIL_PEER_IDLE_DAYS`). Linked Devices can remove one phone.
- **State at rest.** RoachClaw state, RoachTail state and the runtime's server-info file are created readable by your account only. Webhook secrets are stored as salted HMAC-SHA256 digests.
- **Supply chain.** Every file in the bundled speech packs is checked against committed SHA-256 digests at build time, and those digests are traced to the pinned Hugging Face commits. The build stamps its source commit into the app (About, `roachnet-runtime --build-info`). The signing pipeline scopes its secrets to the steps that use them.
- The 1.0.7 Host, Origin and body checks cover every local service, including the Ollama-compatible model server.

## Opening the installer

This build is **ad-hoc signed and not Apple-notarized**, like 1.0.7. On first launch macOS says RoachNet Setup cannot be verified: open System Settings › Privacy & Security and choose **Open Anyway** for RoachNet Setup. Verify the download first:

```sh
shasum -a 256 -c RoachNet-Setup-macOS.dmg.sha256
```

Homebrew: `brew tap --force RoachWares/roachnet && brew install --cask roachnet`

## Upgrade, rollback and removal

- **Upgrade:** quit RoachNet and run Setup over the existing install. `~/RoachNet/storage` (Vault, settings, models, Org) is kept, and Setup removes the old bundled Ollama runner. Back up storage first if you can.
- **Rollback:** going back to 1.0.7 over 1.1 storage is not tested. Webhook secrets saved by 1.1 are stored in a format 1.0.7 can't check, so re-create them after a rollback. Keep a copy of storage from before the upgrade if you might roll back.
- **Removal:** quit RoachNet, then remove `~/RoachNet/app` and `~/RoachNet/runtime`. Keep `~/RoachNet/storage` to keep your data.

## Known limitations

| Limitation | Impact | Workaround |
| --- | --- | --- |
| Ad-hoc signed, no Developer ID or notarization. | Gatekeeper blocks the first launch of RoachNet Setup. | **Open Anyway** in Privacy & Security, once. |
| RoachNet Cluster was tested with two RoachNet runtimes on one Mac, not yet across two physical Macs. | Splitting across real Macs may still turn up network issues. | Report them on GitHub; a model that fits one Mac never needs the cluster. |
| On qwen3 8B, RoachInference evaluates prompts at about 68% of Ollama's speed and decodes at about 85%. Speculative decoding isn't in 1.1. | Long prompts on large models take longer than in Ollama. | `ROACHNET_INFERENCE_ENGINE=ollama` uses an Ollama you installed yourself. |
| RoachInference reads Llama, Mistral, Qwen2 and Qwen3 models. Other architectures (Gemma, Phi or qwen3.5, for example) don't load. | The model server says the architecture isn't supported yet. | Use a supported model, or an Ollama you installed yourself. |
| Gemini CLI, OpenCode and Cursor CLI agents were built to each tool's documented interface; only Claude Code and Codex were run live. | A CLI update could change what those three report. | Report it on GitHub. |
| Plan models need the official Claude Code or Codex CLI, installed and signed in. | `claude:` and `codex:` models are listed only when the CLI is there. | Install and sign in to the CLI, then turn plans on in Settings › RoachClaw › Subscriptions. |
| Scripts that called the local API directly (curl, shortcuts) need a token now when RoachNet.app started the runtime. | They get 401. | Make a RoachClaw API token in Settings › RoachClaw and send it as `Authorization: Bearer …`. |
| Network-backed lanes (catalogs, maps, archives, updates, model downloads, remote providers) need a connection. | They can't refresh or download offline. | Download content and local models ahead of time. |
| Windows and Linux installers are not shipped. | — | Use an Apple Silicon Mac. |
