# RoachNet 1.0.7

Release date: 2026-10-11
Version/build: 1.0.7 / 107
Platform: Apple Silicon Mac, macOS 14 or later
Installer: `RoachNet-Setup-macOS.dmg` (ad-hoc signed, not Apple-notarized — see "Opening the installer" below)
Companion: RoachNet-iOS 0.2.0 (unchanged, separate release)

RoachNet 1.0.7 is a security and content patch for 1.0.6. It closes a DNS-rebinding hole in the local API, makes every local service refuse requests from other websites, brings the bundled library catalog back in line with what Kiwix serves, and updates the bundled Ollama to 0.40.3. Everyone on 1.0.6 should update. It was gated by hand on an M2 Pro running macOS 26.6.1 (`docs/release-gates/1.0.7-mac-gate-results.md`).

## Security fixes

- **DNS rebinding through look-alike names.** 1.0.6 accepted any `Host` header that started with `127.` as local. `127.<some domain>` is an ordinary DNS name, so a web page could point one at your Mac and read or drive the local RoachNet API while RoachNet was running. The 1.0.6 notes said Host checks closed DNS rebinding; this case slipped through. The runtime and the setup service now accept only `localhost`, `::1` and dotted-quad `127.x.x.x` addresses.
- **Cross-site requests.** Every local service (runtime API, setup service, and the JavaScript fallbacks Setup uses when the native helper is missing) now refuses a request whose `Origin` is another site, and refuses request bodies that are not JSON. Browsers can no longer fire requests at them from a web page, including bodiless ones.
- **Download descriptors** are only opened from `https://apps.roachnet.org/downloads/`. Any other `.json` link downloads as the file it names, so no other host can redirect a download.
- Error responses no longer echo non-error values back to the caller.
- The release workflow no longer uses a dependency cache in its privileged jobs.

Found while clearing the repository's code-scanning alerts (0 open on `main` after this release's fixes).

## Other changes

- **Library catalog refreshed.** 1.0.6 shipped the June catalog, and 124 of its Kiwix downloads no longer resolved. Every title is re-pinned to the version the Kiwix library serves today, 20 titles their publishers withdrew are hidden from the installers, and 10 titles are new: MDWiki, WikEM, Ready.gov, Simple English Wikipedia, DevDocs (JavaScript, Python, SQLite, HTML), the OpenStreetMap wiki and RationalWiki. The catalog matches apps.roachnet.org.
- **Bundled Ollama 0.40.3**, checksum-verified against the GitHub release (same file list as 0.40.2). Upstream changes: background model upgrades pause while requests run, and two launch-command warnings are gone.
- **1.1 feature packs in the store.** apps.roachnet.org now lists the RoachSpeech feature packs that install through RoachNet 1.1. Asking 1.0.7 (or the iOS companion paired with it) to install one says it needs RoachNet 1.1, instead of "unknown install action".

## Opening the installer

This build is **ad-hoc signed and not Apple-notarized**, like 1.0.6. On first launch macOS says RoachNet Setup cannot be verified: open System Settings › Privacy & Security and choose **Open Anyway** for RoachNet Setup. Verify the download first:

```sh
shasum -a 256 -c RoachNet-Setup-macOS.dmg.sha256
```

Homebrew: `brew tap --force RoachWares/roachnet && brew install --cask roachnet`

## Upgrade, rollback and removal

- **Upgrade:** quit RoachNet and run Setup over the existing install. `~/RoachNet/storage` (Vault, settings, models) is kept. Back it up first if you can.
- **Rollback:** 1.0.6 and 1.0.7 use the same storage format, but going back to 1.0.6 brings the security hole back.
- **Removal:** quit RoachNet, then remove `~/RoachNet/app` and `~/RoachNet/runtime`. Keep `~/RoachNet/storage` to keep your data.

## Known limitations

| Limitation | Impact | Workaround |
| --- | --- | --- |
| Ad-hoc signed, no Developer ID or notarization. | Gatekeeper blocks the first launch of RoachNet Setup. | **Open Anyway** in Privacy & Security, once. |
| The bundled Ollama 0.40.3 has the same open upstream advisories as 0.40.2 (crafted-model and crafted-request denial of service, no auth on model management), with no fixed version. | Another process on the same Mac could crash Ollama or manage its models. | Ollama binds to `127.0.0.1` and checks the `Host` header, so web pages and other machines can't reach it. 1.1 replaces it with RoachNet's native engine. |
| Network-backed lanes (catalogs, maps, archives, updates, model downloads, remote providers) need a connection. | They can't refresh or download offline. | Download content and local models ahead of time. |
| Windows and Linux installers are not shipped. | — | Use an Apple Silicon Mac. |
