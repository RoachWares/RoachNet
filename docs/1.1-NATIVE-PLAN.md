# RoachNet 1.1 plan: native agent org and native inference

1.0.6 ships first, from `release/v1.0.6-polish`, as a Node-free unsigned pre-release. The 1.1 work lives on `feature/1.1-native-ai`.

Decisions recorded on 2026-10-08:

- **Design references never block a release.** The ideas RoachNet takes from other projects are written as RoachNet code. Nothing from those projects is bundled, linked, vendored or downloaded at runtime, and `scripts/audit-upstream-projects.mjs` enforces that.
- **Inference engine: our own, with hand-written Metal only.** No Ollama, llama.cpp, MLX, Core ML, Metal Performance Shaders or Accelerate. The engine is Swift, plus Metal Shading Language kernels compiled at runtime from source in this repository. Model weights are user data downloaded as GGUF files, not code.
- **Agent org: local first, optional adapters.** Agents run on RoachClaw's native engine by default. External agent CLIs, HTTP agents and the cloud providers already configured in RoachClaw are opt-in adapters.
- **Multi-user over RoachTail.** The org supports invited members with roles and permissions across paired devices.

## Workstream A: RoachInference (`native/macos/Sources/RoachInference`)

| Milestone | Scope | Verification |
| --- | --- | --- |
| A1 Model format | Memory-mapped GGUF v2/v3 reader. Tensor types F32, F16, BF16, Q4_0, Q4_1, Q5_0, Q5_1, Q8_0, Q2_K–Q6_K. Row dequantization and quantized dot products. | Every tensor in the test models matches the reference dequantizer. |
| A2 Tokenizers | SentencePiece-style (score merges, byte fallback) and byte-level BPE (rank merges, per-model pre-tokenizer rules). Special-token splitting and streaming UTF-8 detokenization. | Token ids are identical to the oracle on a fixed corpus. |
| A3 Transformer (CPU) | llama, mistral, qwen2 and smollm families: RMSNorm, NORM and NEOX RoPE (with frequency factors), grouped-query attention with a KV cache, SwiGLU, tied embeddings, q/k/v biases. Multithreaded over output rows. | Prompt logits match the oracle within tolerance, and greedy continuations agree. |
| A4 Generation | Sampler (temperature, top-k, top-p, min-p, repetition, frequency and presence penalties, seed). Stop tokens and strings, context limits, chat templates detected from GGUF metadata, a cancellable token stream. | Deterministic tests. |
| A5 Metal | Hand-written MSL kernels: quantized matvec per type, RMSNorm, RoPE, attention, softmax, SiLU-mul, residual add. Weights stay quantized in shared buffers. | Kernel-by-kernel parity with the CPU path on Apple Silicon (Mac gate). |
| A6 Service | Model store under `storage/models`, pulls from GGUF URLs with resume and SHA-256, and an Ollama-compatible API in `roachnet-runtime` (`/api/tags`, `/api/show`, `/api/pull`, `/api/delete`, `/api/generate`, `/api/chat`, `/api/embed`, `/api/ps`, `/api/version`). RoachClaw switches with no client changes. | Existing RoachClaw contract tests pass against the native engine. |
| A7 Retire Ollama | Remove the bundled Ollama payload once A5 and A6 match it on the reference Macs. | Install-lane smoke without `runtime/vendor/ollama`. |

Later: batched prefill, KV-cache quantization, speculative decoding, more architectures (gemma, phi3, qwen3, MoE), embeddings models, and a native Jinja subset for chat templates.

## Workstream B: RoachClaw Org (`native/macos/Sources/RoachNetRuntime/Org*`)

This is a native re-implementation of the agent-company model studied in the design reference (Paperclip, MIT). Spec notes are in the project knowledge base. The feature set:

- Companies, members, roles and grants.
- Agents with an org chart, statuses and config revisions with rollback.
- Goals, projects and workspaces.
- Issues with comments, blockers, labels, documents, attachments, work products and inbox state.
- Atomic checkout and execution locks.
- Wake queue with coalescing; heartbeat runs with budget gates, secret references, skill loading, logs, usage and session resume.
- Recovery and escalation; execution policies.
- Approvals, including hire approvals and connection gates (Allowed, Ask first, Off).
- Budgets with warning thresholds and hard stops.
- Routines triggered by cron, webhook or API, with concurrency and catch-up policies.
- Skills with versions, tests and evals.
- Activity log, search, export and import packages.
- Adapters: RoachClaw local, HTTP, process/CLI and cloud provider.
- Multi-user over RoachTail: invites, memberships, API keys and short-lived run tokens.

Milestones:

1. B1: data model and store.
2. B2: work engine (issues, checkout, wake queue, runs).
3. B3: governance and budgets.
4. B4: routines and skills.
5. B5: adapters, with RoachClaw local first.
6. B6: multi-user and auth over RoachTail.
7. B7: portability.
8. B8: native SwiftUI surfaces in RoachNet and approvals in the iOS companion.
