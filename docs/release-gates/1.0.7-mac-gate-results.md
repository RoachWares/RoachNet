# 1.0.7 Mac gate results

- **Machine:** an Apple silicon Mac (M2 Pro, 16 GB) on macOS 26 with Xcode 27 and Swift 6.4.
- **Date:** 2026-10-11
- **Branch:** `release/v1.0.7`

The gate follows `1.0.6-mac-gate-checklist.md`. 1.0.7 is a patch: the security fixes from `main` (#28, #29, #30), the collections refresh, and bundled Ollama 0.40.3.

## Fixes made during the gate

| Change | Why |
| --- | --- |
| RoachSpeech model packs copied into the worktree (`native/macos/Vendor/RoachSpeech/ModelPacks`, untracked) from the 1.0.6 candidate worktree. | The first dist from the fresh 1.0.7 worktree had no speech packs: the scope audit failed and the DMG was 179 MB instead of 394 MB. |
| The app and the companion install route decline the store's `pack` install action with "needs RoachNet 1.1". | apps.roachnet.org now lists the 1.1 RoachSpeech feature packs; `smoke:ios-companion-compat` failed on the live catalog because 1.0.x had no answer for that action. Contract test added. |
| `smoke:macos-install-lanes` accepts `ROACHNET_SMOKE_WORK_ROOT`. | The worktree is on an external drive. A freshly ad-hoc-signed RoachNet.app launched from it waits on macOS's "access files on a removable volume" prompt, which a person has to answer, so the lane hung. With the work root on the internal disk the lane runs unattended. The prompt was left unanswered. |
