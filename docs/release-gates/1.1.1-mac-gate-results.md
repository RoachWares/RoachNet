# 1.1.1 Mac gate results

RoachNet 1.1.1 is a maintenance release from the `v1.1.0` tag (`fddc34b`), through PR #48 (`hotfix/v1.1.1-download-safety` into `release/v1.1`). Candidate: `83efab2`. Apple silicon Mac, macOS 26.6.1, Xcode 27.0, Swift 6.4. Ad-hoc signed, not Apple-notarized, like 1.1.0.

The commits after `83efab2` change one test (`47a0052`, below), the release notes, the changelog and this file.
