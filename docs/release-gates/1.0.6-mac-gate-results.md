# 1.0.6 Mac gate results

- **Machine:** "probook", an Apple M2 Pro (12 cores, 16 GB) running macOS 26.6.1 (25G76) with Xcode 27.0 (27A266a) and Swift 6.4.
- **Date:** 2026-10-09
- **Branch:** `release/v1.0.6-polish`

## Fixes made during the gate

| Commit | Fix |
| --- | --- |
| 074f0f0 | Under Xcode 27 / Swift 6.4, SwiftPM builds `RoachNetApp` with `-parse-as-library`, so the top-level `RoachNetMacApp.main()` no longer compiled. The entry point is now declared with `@main`. |
| 074f0f0 | Provider-secret reads rejected macOS's `/var` → `/private/var` symlink. They also compared paths case-sensitively on case-insensitive APFS. Only folders below the storage or runtime-state root are now checked for symlinks. |
| 4200692 | The install-lane smoke needed Screen Recording to read window titles. The iOS fixture redaction turned whole `apiTokens` / `providerOAuth` objects into strings. Both smokes now run on a stock Mac. |
| 8ea5d6a | ROA-35: the RoachTail pair response had dropped `token` / `peerId`, so the iOS app could not finish pairing. |
| 4483308 | ROA-36: the native runtime had no phone chat, service, account or RoachSync lanes; the iOS app's RoachClaw tab and controls failed against 1.0.6. Restored, with a native-only test. |

## Notes

- The bundled Ollama payload is universal (`x86_64` + `arm64`) and ships about 22 MB of Intel-only `libggml-cpu-*.so` backends. Thinning it would shrink the DMG. Bundled Ollama is retired in 1.1 anyway (ROA-30).
- Models on the external MediaSSD page in slowly the first time they load. Copied to the internal SSD, the same model's prompt time dropped from about 15 s to 0.8 s.
