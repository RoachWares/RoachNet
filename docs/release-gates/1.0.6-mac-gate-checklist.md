# 1.0.6 Mac gate checklist (native runtime)

Run this list on an Apple Silicon Mac before tagging `v1.0.6`. The source lane was validated on Linux aarch64 with Swift 6.3.3:

- the runtime build, 81 Node contract and setup tests (78 pass, 3 macOS-only skips), and 12 runtime XCTests;
- the release-scope, parity, release-configuration, public-surface and runtime-freshness audits;
- the iOS companion smoke, up to the `xcodebuild` step.

The app targets, packaging, signing and real installs below have **not** run yet. Record results next to each step in the candidate record.

Paths assume the candidate worktree is at
`<workspace>/RoachNet-candidate-t_57a38fcf`
on branch `release/v1.0.6-polish`.

## 1. Source gates on macOS

```sh
npm ci
npm run runtime:build
npm run test:native-runtime        # expect 0 failures; the 3 ditto tests now run instead of skipping
npm run native:test                # all XCTests, including RoachNetAppTests
xcrun swift build --package-path native/macos -c release 2>&1 | grep -E 'warning:|error:'   # first macOS compile of the app wiring
```

The files that have only been typechecked on Linux, or not compiled at all, are:

- `RoachNetSetup/main.swift`, which starts the native helper;
- `RoachNetApp/main.swift`, which accepts `roachnet-install.json`;
- the `RoachNetCore` launch changes.

Fix any compile error there first.

## 2. Package an unsigned pre-release

```sh
ROACHNET_CANDIDATE_BUILD=1 npm run native:dist     # checksum-pinned Ollama 0.40.2, ad-hoc signed, no notarization
ROACHNET_REQUIRE_FRESH_DIST=1 node scripts/audit-native-release-scope.mjs
ROACHNET_REQUIRE_FRESH_DIST=1 node scripts/audit-runtime-freshness.mjs
npm run audit:privacy        # from 1.1.1: both apps and the DMG carry no paths, host names or LAN addresses of the build Mac (native:dist also runs it)
H=native/macos/dist/RoachNet.app/Contents/Helpers/roachnet-runtime
lipo -archs "$H"; otool -L "$H"; "$H" --version      # arm64 · /usr/lib + /System only · 1.0.6
test ! -e native/macos/dist/RoachNet.app/Contents/Resources/EmbeddedRuntime && echo "no embedded Node"
du -sh native/macos/dist/*.app native/macos/dist/RoachNet-Setup-macOS.dmg   # compare with 404M / 540M in 1.0.5
```

## 4. Hands-on installs (use a spare macOS user account)

| Check | Pass condition |
| --- | --- |
| Fresh install from the DMG | Gatekeeper blocks the first launch. **Open Anyway** in Privacy & Security launches Setup. The install finishes and RoachNet opens from `~/RoachNet/app/RoachNet.app`. |
| Preflight refusals | Choosing the mounted DMG, or a read-only folder, is refused with a clear message. |
| Upgrade over 1.0.5 | Vault, settings and models in `~/RoachNet/storage` survive, as does `~/RoachNet/setup` (Homebrew) and any user files at the root. No `RoachNet.backup-*` or `.staging-*` folders remain. |
| Interrupted install | Quitting Setup mid-install lets the backend finish the install before it exits. Force-killing it (`kill -9`) and then re-running Setup removes the stale staging folder, restores any root that was moved aside, and succeeds. |
| No Node anywhere | `pgrep -fl node` shows nothing from RoachNet. `pgrep -fl roachnet-runtime` shows one runtime while the app is open, and none a few seconds after quitting. |
| RoachClaw on Ollama 0.40.2 | Pulling `qwen2.5-coder:1.5b` and completing a chat both work. If either fails, restore the 0.40.1 pin in `runtime-freshness.json`. |
| RoachTail alias | One administrator prompt, then `http://RoachNet:<port>` resolves to loopback. Declining the prompt does not fail the install. |
| iOS companion | Pairing, runtime summary, Vault list and RoachTail status all work from the phone. |
| Homebrew (local) | From `Sites/homebrew-roachnet`, on branch `release/v1.0.6-native`, run `ROACHNET_CASK_LOCAL_DMG=<dmg> ROACHNET_CASK_LOCAL_SHA=$(shasum -a 256 <dmg> \| cut -d' ' -f1) brew install --cask ./Casks/roachnet.rb`. It installs through `roachnet-runtime --install`. |
| Removal | Deleting `~/RoachNet/app` and `~/RoachNet/runtime` leaves `storage/` intact. Reinstalling picks the storage back up. |
