Last updated: 2026-05-25

- Desktop: `RoachNet 1.0.5`

## Known Release Limits

- No Apple Developer ID is available. `security find-identity -v -p codesigning` returns `0 valid identities found`, so the release is still unsigned/unnotarized.
- Gatekeeper will still warn users because the build is unsigned. This is a trust limitation, not a missing local functionality gate.
- RoachWares.org and the OwnCast stream/live surfaces are separate company/broadcast work. RoachNet.org remains the product home for this release.
- Worker 6 brand-kit/biography deliverable happens after release publication so it captures the final v1.0.5/v0.1.5 state.
