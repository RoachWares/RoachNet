# iOS simulator pairing check

`run.sh` checks RoachTail pairing between a `roachnet-runtime` and the RoachNet-iOS companion on an Xcode simulator. All iOS pairing work uses simulators rather than physical phones.

```sh
ROACHNET_IOS_REPO=/path/to/RoachNet-iOS scripts/ios-simulator-pairing/run.sh [path/to/roachnet-runtime]
```

What `run.sh` does:

1. Runs the runtime (by default the packaged dist helper) with a throwaway storage root, and with the companion bridge on loopback.
2. Creates a fresh simulator. By default it's an iPhone 17 Pro on the newest installed iOS runtime.
3. Builds the RoachNet-iOS working tree for that simulator and installs it.
4. Runs `SimPair.xcodeproj`'s XCUITest, which:
   - opens the `roachnet://pair` deep link with the join code;
   - accepts iOS's "Open in" confirmation;
   - presses **Pair with RoachTail**;
   - waits for **Paired over RoachTail**, then for **Phone to Mac link is live.** on the Runtime tab.
5. Passes only if the UI test passes and the desktop lists the iOS peer as `connected`.

The simulator and runtime are removed afterwards. Screenshots and logs stay in the printed work directory.

You can override these with environment variables: `ROACHNET_SIM_DEVICE`, `ROACHNET_SIM_RUNTIME`, `ROACHNET_SIM_RUNTIME_PORT`, `ROACHNET_SIM_BRIDGE_PORT`, `ROACHNET_SIM_WORKDIR`, and `ROACHNET_SIM_KEEP_BUILD=1` (keeps the build folders, which are deleted by default).

`SimPair.xcodeproj` is generated by `gen.rb`, which needs the `xcodeproj` gem. The generated project is checked in, so running the check doesn't need the gem.
